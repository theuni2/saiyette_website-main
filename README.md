# Pink For Purpose | Saiyette Website

A modern, high-performance web application dedicated to Breast Cancer awareness, early detection, and patient support.

## Core Mission

Empowering women through awareness, support, and early detection. Our mission is to raise awareness about breast cancer, promote early screening, and support patients and survivors through education, empathy, and action.

## Tech Stack

- **Frontend**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & Phosphor Icons
- **Components**: Radix UI (Shadcn UI)

## Key Features

- **Dynamic Hero Section**: High-impact typography with background-clipped imagery and floating decorative elements.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop experiences.
- **Interactive Backgrounds**: Subtle dot patterns and floating theme-relevant icons (Ribbons, Hearts, Footprints) to fill negative space and enhance visual engagement.
- **Smooth Transitions**: Micro-animations and scroll-linked effects for a premium feel.

## Getting Started

### Prerequisites

- Node.js 18+
- npm / pnpm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `app/`: Next.js App Router pages and global styles.
- `components/`: Reusable UI components.
- `lib/`: Utility functions and constants.
- `public/`: Static assets (images, logos).
